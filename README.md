# osu! Beat Sound（ビート音アプリ）

NM（NoMod）のままプレイ中に、曲のビートに合わせて好きな音（NCのキック音など）を鳴らすアプリです。
osu!本体には一切触らず、tosuから曲の再生位置を受け取って音を鳴らすだけです。

## 必要なもの
- Windows 10 / 11
- osu!（stable）
- [tosu](https://github.com/KotRikD/tosu)（osu!の情報を取得するツール。先にインストールしてください）
- Python 3.10 以上（https://www.python.org/downloads/ ）
  - インストール時、最初の画面の **「Add python.exe to PATH」に必ずチェック**を入れてください
- 鳴らしたい音声ファイル（wav / ogg / mp3）
  - ※音声ファイルは付属していません。ご自身で用意してください

## 初回セットアップ（1回だけ）
1. zipを展開します（右クリック →「すべて展開」）。
2. 展開した `osu_beat_sound` フォルダを開き、上部のアドレスバーに `cmd` と入力してEnterを押します。黒い画面が開きます。
3. 黒い画面に、次の2行を1行ずつ入力してEnterを押します。

       python -m pip install -r requirements.txt
       python -m pip install websocket-client

   （`pip` が認識されないエラーが出ても、`python -m pip` なら動きます）

## 音声ファイルの入れ方
`sounds` フォルダに、次のどれかの名前で入れます。ないものは鳴りません（1つだけでもOK）。

| 役割 | ファイル名の例 |
|---|---|
| キック | `kick.wav` / `nightcore-kick.wav` |
| クラップ | `clap.wav` / `nightcore-clap.wav` |
| ハット | `hat.wav` / `nightcore-hat.wav` |
| フィニッシュ | `finish.wav` / `nightcore-finish.wav` |

拡張子は wav / ogg / mp3 が使えます。

## 起動のしかた（毎回）
1. tosuとosu!を起動します。
2. `osu_beat_sound` フォルダで、アドレスバーに `cmd` と入力してEnterを押し、次を実行します。

       python nc_beat.py

3. 小さなウィンドウが開きます。「tosu」が **接続OK** になっていれば準備完了です。
4. osu!で曲をプレイすると、ビートに合わせて音が鳴ります。

## 画面の見かた
- **音量**: 音の大きさ
- **タイミング**: 音が合わないときの調整です。マイナスで遅く、プラスで早く鳴ります
- **BPM倍率**: x2 にするとBPMの2倍で、x0.5 にすると半分で鳴らします（例: 160BPMの譜面でノーツが320で並んでいるとき）
- **鳴らす音**: 音ごとのON/OFFと、▶での試聴
- **曲選択画面でも鳴らす**: チェックを入れると、曲選択中にも鳴ります
- **サウンドを再読み込み**: 起動後にsoundsの中身を変えたときに押します

設定はウィンドウを閉じるときに `config.json` へ保存されます。
本物のNCモッドをつけているときは、二重に鳴らないよう自動で止まります。

## リズムのパターンを変える
`config.json` を開き、`pattern_4_4` を編集します。1小節を8分音符8個（0〜7）として、鳴らす位置を数字で指定します。
例: キックを毎拍に鳴らす → `"kick": [0, 2, 4, 6]`
編集は、アプリを閉じた状態で行ってください。

## うまくいかないとき
| 症状 | 対処 |
|---|---|
| `python` が認識されない | Pythonを入れ直し、「Add python.exe to PATH」にチェック。そのあと黒い画面を開き直す |
| `pygame` のインストールに失敗する | `python -m pip install pygame-ce` を実行する |
| tosuが「接続できません」 | tosuを先に起動する |
| 読込済み音が「なし」 | ファイル名と拡張子（`clap.wav.wav` のような二重拡張子に注意）を確認し、再読み込みを押す |
| 音が鳴らない | 曲の「状態」が `play` になっているか確認。▶ボタンで試聴できるかも確認する |
| 音がずれる | 「タイミング」スライダーで調整 |
